# 누구나 오픽 — 콘텐츠 작성 규칙

앱 목표: 왕초보도 OPIc **IM2**에 도달하도록, 모범 답변을 **IM2판 + IH판** 두 수준으로 제공하고 외워서 쓰게 한다.
사용자는 한국인. 앱 UI·설명은 한국어. 영어는 **자연스러운 미국식 구어체**(원어민이 실제 말하는 문장).
**기출 교재·학원 자료의 문장을 옮기지 말 것.** 질문과 답변은 모두 새로 작성한다.

## 1. 공통 인물 설정 (모든 답변이 같은 '나')
서베이(국룰): 일 경험 없음 · 학생 아님 · 혼자 거주 · 영화/공연/콘서트/공원/쇼핑 · 음악 감상 · 조깅/걷기 · 국내·해외여행/집에서 보내는 휴가
- **직업·회사·학교 이야기를 하지 않는다** (일 경험 없음 설정). "평일엔 바빠서", "주말에" 정도로만.
- 서울의 작은 아파트(3층, 원룸 + 작은 부엌 + 욕실, 큰 창문 밖으로 공원이 보임)에 **혼자 산 지 3년**. 회색 소파, 큰 TV, 화분 몇 개, 하얀 벽.
- 집에서 걸어서 5분 거리에 **한강 공원**(Han River park) — 저녁마다 30분 걷기, 주말 아침엔 조깅.
- 영화: 액션·코미디 좋아함, 마블 영화, 집에서는 넷플릭스, 극장은 친구 **Minsu**와 한 달에 한두 번.
- 음악: 발라드·팝, 이동할 때·청소할 때 이어폰으로, 좋아하는 가수는 이름 대신 "my favorite singer".
- 쇼핑: 온라인(옷·생활용품) + 가끔 백화점/쇼핑몰. 
- 여행: 국내는 **제주도**(가족과), 부산. 해외는 **일본 오사카**(친구들과).
- 집에서 보내는 휴가: 늦잠, 대청소, 요리, 영화 몰아보기.

## 2. 이야기 은행 (과거 경험 답변에서 재사용 — 세부 사실을 바꾸지 말 것)
- **S1 제주 여행 폭우**: 2년 전 여름 가족과 제주, 둘째 날 폭우로 계획 취소 → 근처 작은 카페·실내 박물관 → 오히려 가장 기억에 남음.
- **S2 오사카 휴대폰 분실**: 작년 겨울 친구 둘과 오사카, 지하철역에서 휴대폰 분실 → 역무원에게 서툰 영어·번역 앱(친구 폰)으로 설명 → 다음 날 분실물 센터에서 찾음 → 일본 사람들 친절에 감동.
- **S3 첫 콘서트**: 5년 전 처음 간 좋아하는 가수 콘서트, 야외 공연장, 비가 왔지만 모두 우비 입고 떼창 → 소름.
- **S4 조깅 중 발목**: 작년 봄 한강 공원에서 조깅하다 젖은 길에 미끄러져 발목 삠 → 2주 못 뜀 → 지금은 준비운동·밝을 때만 뜀.
- **S5 온라인 쇼핑 사이즈**: 몇 달 전 온라인으로 코트 주문 → 사이즈가 너무 큼 → 고객센터 채팅으로 교환 요청 → 일주일 걸림 → 이제 리뷰·사이즈표 꼭 확인.
- **S6 이사·집 꾸미기**: 3년 전 지금 집으로 이사, 처음엔 텅 비어 있었음 → 주말마다 가구·화분·조명 하나씩 → 지금은 가장 편한 곳.

## 3. 두 수준의 기준
| | IM2판 | IH판 |
|---|---|---|
| 길이 | **6~10문장, 70~110단어** | **11~16문장, 140~200단어** |
| 문장 | 짧고 쉬운 문장, 현재·과거·미래 기본형 | 문장 길이 다양, 시제 넘나들기(과거 이야기 + 지금 생각), 현재완료 일부 |
| 연결 | and, but, so, because, also, then, after that | 위 + At first, Eventually, To be honest, Actually, Anyway, which was… |
| 구성 | 시작 1문장 → 내용 → 마무리 1문장 | 시작 → 구체적 세부(언제·어디·누구·무엇·느낌·이유) → 마무리(지금의 생각) |
| 어휘 | 중학 수준 단어 | 고교 수준까지, 어려운 단어 금지 |
- 둘 다 **질문에 정확히 답할 것** (과거 경험 질문 → 과거형 이야기, 루틴 질문 → 현재형 습관, 비교 → 과거 vs 현재).
- 자연스러운 군말 1개 정도 허용: "Well,", "Let me think…", "You know,".
- 롤플레이 질문하기(rp_ask)는 **질문 3~4개**를 반드시 포함. 문제 해결(rp_solve)은 **상황 설명 + 대안 2~3개 제시**.

## 4. 질문 유형 코드
`intro` 자기소개 · `desc` 묘사 · `routine` 습관·루틴 · `past` 과거 경험 · `compare` 과거와 현재 비교 · `rp_ask` 롤플레이 질문하기 · `rp_solve` 롤플레이 문제 해결 · `rp_exp` 롤플레이 관련 경험

## 5. 출력 형식 (JSON 파일 하나, UTF-8)
```json
{ "cluster": "home", "items": [
  { "id": "home-desc-1", "cluster": "home", "topic": "집", "type": "desc",
    "q": "You indicated in the survey that you live alone. Describe your home for me. What does it look like? How many rooms does it have?",
    "qko": "설문에서 혼자 산다고 하셨네요. 집을 묘사해 주세요. 어떻게 생겼고 방은 몇 개인가요?",
    "tip": "이 유형의 답변 요령 한두 줄 (한국어)",
    "im2": [["Well, I live alone in a small apartment in Seoul.", "음, 저는 서울의 작은 아파트에 혼자 살아요."], ["...", "..."]],
    "ih":  [["...", "..."]],
    "chunks": [["live alone", "혼자 살다"], ["It's not that big, but", "그렇게 크진 않지만"]],
    "story": "S6" }
]}
```
- `q`: Ava가 읽는 영어 질문 (OPIc 스타일, 2~3문장, 새로 작성). `qko`: 자연스러운 한국어 번역.
- `im2`, `ih`: **[영어 한 문장, 한국어 번역]** 쌍의 목록. 한 쌍 = 한 문장(따라 말하기·외우기 단위).
- `chunks`: 그 답변에서 꼭 외울 덩어리 표현 **4~6개** `[영어, 한국어]`. 영어 덩어리는 **im2 또는 ih 본문에 글자 그대로 들어 있어야** 한다(대소문자 무관).
- `story`: 이야기 은행을 쓴 경우 S1~S6, 아니면 생략.
- `tip`: 그 질문 유형·주제에서 점수 따는 요령 (예: "과거 경험은 언제→무슨 일→어떻게 됐나→느낌 순서, 과거형 유지").
- id 규칙: `<cluster>-<type>-<번호>` (같은 cluster 안에서 유일).

## 6. 자기 점검 (제출 전)
1. JSON이 올바른가 (python -c "import json;json.load(open(...,encoding='utf-8'))").
2. 각 im2 단어 수 70~110, ih 140~200 (영어만 세기).
3. chunks 영어가 본문에 그대로 있는가.
4. 직업·회사·학교 언급이 없는가. 인물 설정·이야기 은행 사실과 모순이 없는가.
5. 롤플레이 질문하기에 질문 3~4개, 문제 해결에 대안 2~3개가 있는가.
