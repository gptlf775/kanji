📲 홈 화면에 추가하기 (앱처럼 쓰기)

아이폰 (Safari)

  1. Safari로 gptlf775.github.io/kanji 열기
  2. 아래쪽 공유 버튼 ⬆︎ 누르기
  3. '홈 화면에 추가' → 추가

안드로이드 (Chrome)

  1. Chrome으로 같은 주소 열기
  2. 오른쪽 위 ⋮ 메뉴 → '홈 화면에 추가' (또는 '앱 설치')
💡 홈 화면에서 열면 주소창 없이 앱처럼 보이고, 한 번 열어 두면 인터넷이 없어도 열려요. 공부 기록은 내 폰에만 저장돼요.

🧭 추천 사용법

🧒 어린이 (초등학생)

  • 처음 켤 때 어린이 모드 → 하루 4자, 쉬운 설명과 외우기 이야기
  • 매일 '공부 시작!' 한 번이면 끝. 다 하면 스티커를 받아요

🧑 어른 (일본어 공부)

  • 어른 모드 → 하루 7자, 읽기 중심
  • 가나가 처음이면: 한 장 정리 → 히라가나 → ✏️ 연습
  • 문법은 🔀 활용어 → 📘 기초부터, 단어는 📒 단어장 → '상위 100'부터

❓ 자주 묻는 질문

정말 무료인가요?

네. 광고·결제·회원가입이 없어요. 개인이 만든 학습 도구예요.

공부 기록은 어디에 저장되나요?

각자 폰(브라우저) 안에만 저장돼요. 서버로 보내지 않아서 다른 사람이 볼 수 없어요.

폰을 바꾸면 기록이 사라지나요?

앱의 ⚙️ 설정 → 백업 코드 만들기로 코드를 복사해 메모 앱에 저장해 두세요. 새 폰에서 '불러오기'에 붙여 넣으면 이어서 할 수 있어요.

소리가 안 나와요

폰의 일본어 음성을 써요. 아이폰: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 일본어 음성을 받아 주세요. 무음 모드도 확인해 주세요.

JLPT 공식 자료인가요?

아니요. N5·N4 구분은 공식 목록이 없어 일반적인 학습 목록(비공식) 기준이에요. 한자 목록·학년은 일본 문부과학성 학년별 한자 배당표를 따랐어요.
