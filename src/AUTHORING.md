# 한자 콘텐츠 작성 지침 (2~6학년 공통)

대상: 한국 초등학생(아이 모드)과 한국 성인(어른 모드)이 일본 초등 한자를 배우는 앱.
**완성 예시(반드시 먼저 읽고 문체·밀도를 그대로 맞출 것)**: `src/content_g1.json` (1학년 80자).

## 1. 입력
- 작성 참고표: `../일본어한자_원천데이터/ref/ref_gN.txt`
  (글자 | 획수 | 부수 | 상용한자표 음훈 | 한국음 | 영어 뜻)
- 이 참고표의 글자 목록이 곧 그 학년의 **공식 배당 한자 전체**다. 하나도 빠뜨리거나 더하지 말 것.

## 2. 출력 파일 (src/ 안)
- `content_gN_themes.json` : `{"grade": N, "themes": [{"name": "주제명", "e": "이모지", "ks": "글자들"}, ...]}`
  - 그 학년 전 글자를 **겹치지 않게 모두** 주제로 묶는다(주제당 8~25자). 주제 순서 = 학습 순서.
    구체적·쉬운 주제 → 추상적 주제 순. 같은 소리 부품(형성자) 가족을 가능하면 한 주제에 모은다.
- `content_gN_p1.json`, `content_gN_p2.json`, … : `{"items": [ ... ]}` — **파일 하나에 25자 이하**.

## 3. 항목(item) 형식 — 1학년과 완전히 동일
```json
{"k":"晴","hun":"갤 청","m":"맑다, 개다","e":"☀️","t":"형성","p":"日(해) + 青(소리 セイ)",
 "o":"진짜 유래 (쉬운 해요체, 1~3문장)",
 "mm":"외우기 이야기 (재미있고 기억에 남게, 1~2문장)",
 "ad":"어른용 깊은 설명 (1~3문장)",
 "tip":"이럴 땐 이 발음 — 한 줄 요약",
 "ex":[["晴れ","はれ","は-れる","맑음"],["快晴","かいせい","セイ","쾌청"]],
 "sp":[["단어","よみ","뜻","설명"]]}
```

### 필드 규칙
| 필드 | 규칙 |
|---|---|
| hun | 한국 훈음 "뜻 음" (예: `갤 청`). **음은 참고표의 한국음 중 하나**여야 함. 음이 둘이면 `수레 거/차` |
| m | 한국어 뜻 짧게 (쉼표로 2~3개까지) |
| e | 뜻을 떠올리게 하는 이모지 1개 |
| t | `상형`/`지사`/`회의`/`형성`/`가차`/`회의 겸 형성`/`국자`(일본에서 만든 글자: 畑·働 등) 중 하나 |
| p | 구성 부품 설명. 형성자는 반드시 `뜻 부분 + 소리 부분(소리 ○○)` 형태 |
| o | **진짜 유래(字源)** — 학계 통설만. 확실하지 않으면 "학설이 여러 가지예요"라고 솔직하게. **지어낸 어원 금지** |
| mm | **외우기 이야기** — 지어낸 이야기 OK. 모양을 쪼개 이야기로 (예: "나무(木) 옆에 서서(立) 보는(見) 사람 = 부모 親") |
| ad | 어른용: 소리 부품 가족(같은 음독 한자들), 한국음↔음독 대응, 비슷한 한자 구별, 일본 약자/한국 정자 차이(예: 国/國), 쓰임 뉘앙스, 동훈이자(はかる: 計る·測る·量る·図る 등) |
| tip | 읽기 고르는 요령 한 줄 (예: "맑음은 はれ, 한자어는 せい") |
| ex | 예시 단어 3~5개 (아래 규칙) |
| sp | 상용한자표 부표(付表)의 특별 읽기(熟字訓·당자) 중 이 글자가 들어간 것만. 없으면 `[]` |

### 예시 단어(ex) 규칙 — 자동 검증되므로 정확히
각 예시 = `[단어, 단어 전체 읽기(히라가나만), 이 한자의 읽기 표기, 한국어 뜻]` (+ 선택 5번째 값 `1`)
1. **3번째 값은 참고표 음훈 표기를 글자 그대로** 복사: 음독은 가타카나(`セイ`), 훈독은 하이픈 포함(`は-れる`),
   괄호 읽기는 괄호만 빼고(`（ショウ）` → `ショウ`).
2. 2번째 값(단어 읽기)은 **히라가나만**(가타카나·공백·장음부호 금지. 외래어 섞인 단어는 피할 것).
3. 단어 읽기 안에 그 한자 읽기가 실제로 들어 있어야 함. 연탁(はな→ばな), 촉음(がく→がっ)은 자동 인정.
   그 외 변형(예: 日本 にほん)은 ex가 아니라 sp로.
4. 주요 읽기(괄호 없는 것)마다 자연스러운 단어가 있으면 1개 이상. 아주 드문 훈독은 생략 가능.
5. 단어는 **초등생도 아는 흔한 말** 우선, 가능하면 그 학년 이하 한자로 된 말.
6. 같은 단어를 다른 읽기로도 읽을 수 있으면(예: 毎年 まいとし/まいねん) 5번째 값 `1`을 붙이고 뜻에 "(○○도 맞아요)".
7. 한 글자 단독 단어(예: `["林","はやし",...]`)도 괜찮다(앱이 자동으로 읽기 퀴즈에서 제외).

## 4. 문체
- o·mm·tip·m: 초등학생이 혼자 읽을 수 있는 **쉬운 해요체**. 한자 부품은 괄호로 뜻을 붙여 준다: `木(나무)`.
- ad: 어른 대상, 간결한 설명체.
- 과장·틀린 정보 금지. 일본 문화 관련 재미있는 사실은 환영(검증된 것만).

## 5. 검증 (완료 조건)
```
cd src
python build.py N
```
- **오류 0건, 경고 0건**이 될 때까지 고친다. INFO(예시 없는 읽기)는 드문 훈독이면 그대로 둬도 됨.
- 보고서: `src/verify_gN.txt`, 결과물: `data/gN.js`
- 다른 학년 파일·index.html·content_g1.json은 **절대 수정하지 말 것**.
