# 📗 문법장 빈칸 연습 문제 작성 기준 (문형마다 1문제)

## 목적
JLPT 문법 문제(もんだい1: 빈칸에 알맞은 말 고르기)와 같은 형식으로, 문법장 각 문형을 **정확히 이해했는지** 확인하는 4지선다 문제.
**정답이 반드시 하나뿐이어야 한다.** 오답 3개는 그럴듯하지만 문맥·접속·뜻으로 분명히 틀려야 한다.

## 입력 / 출력
- 입력: `src/bunpo_q1~4.json` (문법장 카드: id·p·m·c·d·cmp·ex) 중 **맡은 id 범위**.
- 출력: `src/bpq_qN.json` = `{"items":[{"id":"b001","qz":{...}}, ...]}` 맡은 범위 전부, id 순서대로. UTF-8(BOM 없음). 다른 파일 수정 금지.

## 문제 형식
```json
{"id":"b147","qz":{
 "s":"日本語を勉強する（　　）、毎日アニメを見ています。",
 "a":"ために",
 "ch":["ように","ので","のに"],
 "y":"にほんごを べんきょうする ために、まいにち アニメを みて います。",
 "ko":"일본어를 공부하기 위해 매일 애니메이션을 보고 있습니다.",
 "why":"내가 의지로 하는 일의 목적이라 ために. ように는 저절로 되는 일(見えるように), ので는 이유, のに는 '~인데도'라 뜻이 맞지 않아요."}}
```
| 필드 | 규칙 |
|---|---|
| s | 빈칸 `（　　）`(전각 괄호 + 전각 공백 2개)이 **정확히 한 번** 들어간 일본어 문장. 25~35자 안팎. です·ます체 기본(보통체 문형은 보통체) |
| a | 정답 — 빈칸에 들어갈 말. 이 카드의 문형(활용된 꼴 포함)이 정답이 되게 |
| ch | 오답 3개 — 서로 다르고 a와 다름. **같은 품사·비슷한 길이·실제로 헷갈리는 것**(그 카드의 cmp에 나온 문형, 같은 묶음의 다른 문형, 접속이 틀린 꼴 등). 문법적으로 어색하거나 뜻이 문맥에 안 맞아 **틀린 것이 분명해야** 함 |
| y | 정답을 넣은 문장 전체의 히라가나 읽기, 어절 띄어쓰기(가타카나 낱말은 그대로) |
| ko | 정답 문장의 한국어 번역 |
| why | 한 줄(80자 안팎) 해설: 왜 정답인지 + 대표적인 오답이 왜 틀린지. 쉬운 해요체 |

## 규칙
- 문제 문장은 카드의 ex 예문을 **그대로 쓰지 말고** 새로 만든다(카드에서 본 문장을 그대로 맞히면 연습이 안 됨). 단어는 N5·N4 수준.
- 문장 속 한자는 초등 한자 위주, 어려운 것은 히라가나.
- 부사·접속사 문제: 빈칸에 부사/접속사가 들어가고, 오답도 부사/접속사. 짝이 정해진 것(けっして～ない, ぜひ～たい 등)은 짝을 단서로.
- 조사 문제: 빈칸 하나에 조사 하나.
- 활용 문제(가능형·수동형 등): 같은 동사의 다른 활용형을 오답으로(書ける / 書かれる / 書かせる / 書こう).
- 정답이 둘이 될 수 있는 문제 금지 — 예: 「雨が降っ（　）、試合は中止です」에 たら·ても 둘 다 될 수 있는 식이면 문장을 고쳐 하나만 되게.
- 어린이에게 부적절한 내용 금지(술·폭력 등).
