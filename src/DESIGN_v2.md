## 목표
일본 초등학교 교육한자 1026자를 **한국인 성인**이 실제 일본어 속에서 보고·읽고·이해하고·장기 기억하게 한다.
- JLPT 분류·단계는 사용하지 않는다. 기준은 학년별 배당 1026자.
- 학습 순서: 모양 → 기본 뜻 → 읽기 → 단어에서 읽기 → 듣기 → 문장에서 읽기 → 복습(장기기억)
- 유래·한자학 설명은 보조 정보. 목적이 되어서는 안 된다.
- 현재 구조(획순·음훈·단어·발음·유래·암기 이야기·심화 설명·문제)는 유지하되, **핵심 정보와 보조 정보를 구분**한다.

## 화면
1. 상단: 학년("초1 배당"처럼 일본 초등 몇 학년 배당인지 명확히)·획수·부수(보조 정보, 학습 목표 아님)
2. 한자 + 짧은 뜻 (예: 四 = 넷 / 4)
3. 읽기 **계층화**: 주요하게 익힐 읽기 / 단어에서 자주 나타나는 읽기 / 그 밖 (모두 같은 무게로 보여주지 않음)
4. **대표 단어 4~7개** (자주 쓰는 말 우선, 읽는 이유는 설명하지 않음) — 누르면 발음
5. **한자 → 단어 → 문장** 3단계 듣기 (예문 + 읽기 + 한국어 번역)
6. **⚠️ 주의할 읽기** 별도 영역 (四日 よっか, 四人 よにん, 四時 よじ) + "특별한 읽기는 단어째로" 한 줄
7. 🏺 한자 유래(사실만, 모르면 "유래 확인 불충분") / 🧠 외우기 이야기(기억 장치임을 명시) — 라벨 분리
8. 🎓 어른을 위한 더 깊은 설명: **항상 접힘**, 펼치면 충분히 깊게
9. **⚠️ 헷갈리기 쉬운 한자** (未↔末, 土↔士, 人↔入, 口↔囗, 日↔曰, 木↔本) — 차이 한 줄

## 콘텐츠 원칙
- A: 사실과 암기법을 섞지 않는다
- B: 유래를 모르면 억지로 만들지 않는다 ("유래 확인 불충분")
- C: 쉬운 한자(山·川·日·月 등)에는 억지 암기법을 넣지 않는다 — 어려운 한자에만
- (기존) 암기 이야기 속 부품 뜻 = 그 글자에서 실제로 맡은 뜻 (AUDIT_MM.md)
