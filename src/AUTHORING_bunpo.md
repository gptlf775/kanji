# 📗 문법장 작성 기준

## 목적
한국인 학습자(어른 중심, 어린이도 사용)가 JLPT N5·N4 문법을 **한 화면에서 이해하고 예문으로 익히도록** 하는 문법 카드.
**정확성이 가장 중요하다.** 일본어 문장·읽기·뜻에 틀림이 없어야 한다.

## 저작권 — 반드시 지킬 것
참조 교재가 있었지만 **교재의 예문·해설을 옮기지 않는다.** 설명과 예문은 모두 새로 쓴다.
(문형 이름 자체는 누구나 쓰는 것이라 괜찮다.)

## 먼저 볼 것
- `data/gram.js` 의 `pat` (기존 앱 문법 131개: p·m·c·d·ex). 같은 문형이 있으면 **그 내용을 출발점으로 다듬고 예문을 2개로** 늘린다. 문체·밀도를 맞춘다.
- `data/gram.js` 의 `tabs` 중 '🔗 조사', '부사', '🙇 경어' — 앱에 이미 있는 설명과 어긋나지 않게.

## 입력 / 출력
- 입력: `src/bunpo_plan.json` 의 items 중 **맡은 id 범위**. (`id, g, lv, p, tag, src` — 이 값들은 바꾸지 않는다. `src`는 내부 메모라 무시)
- 출력: `src/bunpo_qN.json` = `{"items":[{...}, ...]}` 맡은 항목을 plan 순서대로 빠짐없이. UTF-8(BOM 없음). **다른 파일은 절대 수정 금지.**

## 항목 형식
```json
{"id":"b123","p":"～ため（に）",
 "m":"~하기 위해 · ~ 때문에",
 "c":"동사 사전형 / 명사 + の + ために (목적) · 보통형 / 명사 + の + ために (원인)",
 "d":"앞이 '내가 하려는 일'이면 목적(~하기 위해), 이미 일어난 일이면 원인(~ 때문에)이에요. 원인 뜻은 조금 딱딱한 말이라 글·뉴스에 많이 나와요.",
 "cmp":[["～ように","ように는 저절로 되는 일·남의 일(見えるように·忘れないように), ために는 내 의지로 하는 일"]],
 "ex":[["日本へ行くために、お金をためています。","にほんへ いく ために、おかねを ためて います。","일본에 가기 위해 돈을 모으고 있습니다."],
       ["雪のために、電車がおくれました。","ゆきの ために、でんしゃが おくれました。","눈 때문에 전철이 늦었습니다."]]}
```

## 필드 규칙
| 필드 | 규칙 |
|---|---|
| p | plan 값 그대로 |
| m | 한국어 뜻 — 짧게. 뜻이 둘 이상이면 ' · '로 |
| c | 접속(무엇 뒤에 어떻게 붙는지). 앱 표기: '동사 사전형 / た형 / て형 / ない형 / ます형(ます 뺀 꼴)', 'い형용사 ～い', 'な형용사 ～な', '명사 + の'. 접속사·부사·지시어처럼 접속이 없으면 '문장 앞' · '동사·형용사 앞' 등 쓰임 위치 |
| d | 쉬운 설명 1~3문장, 해요체. 한국어와 비교하면 좋음. 문법 용어는 최소로. 시험에 잘 나오는 함정(비슷한 문형과 헷갈림, 정해진 짝)은 꼭 |
| cmp | 0~2개 `[비슷한 문형, 한 줄 차이]` — 진짜 헷갈리는 것만 |
| ex | **정확히 2개** `[일본어 문장, 히라가나 읽기(어절 띄어쓰기), 한국어 번역]` |

## 예문 규칙
- 짧고(25자 안팎) 일상적인 문장. 기본은 です·ます체. 보통체 문형(～だろう·축약형·～なさい 등)은 보통체 회화로.
- **문형이 문장 안에 분명히 보이게.** 2개 예문은 서로 다른 쓰임(뜻이 둘이면 각각 하나씩).
- 단어는 N5·N4 수준(`data/vocab.js`의 단어장 수준)으로. 한자는 초등 한자 위주로 쓰고, 어려운 한자는 히라가나로.
- 읽기는 **히라가나만**(문장에 가타카나 단어가 있으면 그 부분만 가타카나 그대로 허용), 어절마다 띄어쓰기. は·へ 조사는 표기대로 は·へ.
- 사람 이름은 田中さん·山田さん·キムさん 정도만. 폭력·연애·술 등 어린이에 부적절한 내용 금지.
- 번역은 자연스러운 한국어 존댓말(문장이 보통체면 반말).

## 검증 (반드시 실행)
```
cd C:\Users\GAUN\Documents\교육\일본어한자\src
python build_bunpo.py --check bunpo_qN.json
```
**오류 0·경고 0**까지. INFO "읽기 확인 필요"는 형태소 분석기와 다른 것 — 분석기가 틀리는 일이 많으니(日本→にっぽん, 一人→いちにん, 明日→あす 등) **하나씩 직접 판정**.

## 보고 (짧게, 한국어)
항목 수, 오류·경고 수, 기존 pat에서 가져와 고친 것 중 내용을 바로잡은 것(틀렸던 점), 판단이 어려웠던 항목.
