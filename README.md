# 초등 한자 1026

일본 초등학교 1~6학년 한자 1026자(学年別漢字配当表, 2020 시행)를 **간격 반복**으로 익히는 모바일 웹앱입니다.
아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓰고, 한 번 열어 두면 인터넷 없이도 동작합니다.

## 기능
- 한자 카드: 획순 애니메이션(한 획씩·번호), 음독/훈독(누르면 발음), 쓰임별 발음 예시, 특별한 읽기, 한국 훈음
- 구성 풀이: 📜 진짜 유래와 🧠 외우기 이야기를 **구분 표시**
- 간격 반복: 맞히면 1→3→7→14→30→60→120일 뒤 다시, 틀리면 내일 + 오늘 3문제 뒤 재출제
- 문제 5종: 뜻 고르기 / 한자 고르기 / 단어 속 읽기 / 듣고 고르기 / 빈칸(어른)
- 어린이·어른 모드, 한글 발음 표시(참고용), 진도 백업 코드

## 폴더 구조
```
index.html            앱 본체 (HTML·CSS·JS 한 파일)
sw.js                 오프라인 동작 (인터넷 우선 → 실패 시 저장본)
manifest.webmanifest  홈 화면 앱 설정
data/gN.js            학년별 한자 데이터 (build.py가 생성)
src/content_gN.json   직접 작성한 설명·예시
src/build.py          데이터 빌드 + 자동 검증 → src/verify_gN.txt
```

## 데이터 빌드
```
set KANJI_REF=원천데이터폴더   (jouyou.json, kd_grades.json, kvg/*.svg)
python src/build.py 1
```
검증 항목: 공식 배당표와 글자 목록 일치 · 예시 단어의 읽기가 상용한자표 음훈에 있는지 · 그 읽기가 실제 단어 발음 안에 있는지(연탁·촉음 허용) · 한국음이 KANJIDIC2와 일치 · 획순 획수 = 공식 총획

## 알려진 한계
- 한글 발음은 참고용 근사치입니다(장음은 표기대로 표시).
- 발음은 기기의 음성 합성을 사용합니다.
- 초등학교에서 배우는 읽기와 중·고등학교에서 배우는 읽기의 구분(音訓の段階別割り振り表)은 아직 반영하지 않았습니다. 현재는 상용한자표의 음훈 전체를 보여주고, 드문 읽기만 흐리게 표시합니다.
